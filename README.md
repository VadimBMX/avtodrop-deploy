# АВТОДРОП — гра для Telegram (Mini App)

Кейси зі справжніми авто (за рідкістю й за країнами), гараж із пасивним доходом і вітриною, деталі з
кейсів майстерні та злиття 3→1, українські номери, дрег-гонки з перемиканням передач і PvP на ставку,
ринок, аукціони, обмін між гравцями, рівні гравця, завдання новачка й щоденні, колекція з секретними
машинами, тижнева гонка з призами, промокоди та покупка гривень за Telegram Stars.
Без залежностей npm, потрібен Node.js 22.13+ (вбудований SQLite).

    npm start      # http://localhost:3100
    npm test       # тести логіки

## Апгрейд і казино
- **Апгрейд** (як у CS): ставиш до 3 авто, обираєш дорожчу ціль, шанс = вартість ставки / ціна цілі × 0,92 (макс. 75%). Деталі й номери з поставлених авто завжди повертаються на склад.
- **Казино** на ігрові гривні: Краш (RTP 97%, множник рахує сервер за часом), Міни (97%), Рулетка (європейська, 97,3%), Слоти (94,9%, виграш у ~20% спінів).
  Усі результати — з тієї ж перевірюваної випадковості, що й кейси. Досвід за казино входить у денний ліміт.
- ⚠️ Ігрову валюту можна купити за Telegram Stars, а казино — гра на удачу. Перевір правила Telegram і закони своєї країни щодо соціальних казино перед запуском; виведення валюти в грі немає й не повинно бути.

## Оформлення
Стиль «преміум-автоспорт»: графіт, один акцент (сигнальний бурштиновий `#f5b301`), вузький шрифт для заголовків і цифр.
Шрифти Fira Sans Condensed і Manrope (SIL Open Font License) лежать локально в `public/fonts/`, іконки Tabler (MIT) — у `public/icons.svg`.
Кольори класів D…X використовуються лише як смужка й мітка. Палітра — змінні на початку `public/style.css`.

## Фото машин
Промпти для всіх машин (один стиль, вид збоку, машина дивиться праворуч) — у [docs/car-prompts.txt](docs/car-prompts.txt).
1. Генеруй картинку за промптом (Gemini тощо) і клади в `raw-cars/` з назвою-номером машини: `001.png`, `057.jpg`.
   Якщо машина дивиться ліворуч — додай `f` (`005f.png`), і її буде віддзеркалено.
   Файли з номером, покладені помилково в `public/cars/`, скрипт теж підхопить.
2. `npm run cars` — вирізає фон, обрізає й зберігає `public/cars/<id>.webp` (потрібно: `pip install "rembg[cpu]" pillow`).
3. Гра підхопить картинки протягом 30 секунд. Поки картинки немає, показується намальований силует.
Після додавання машин у `public/shared.js` онови список промптів: `npm run prompts`.
Розбір оригінальної гри, на якій базується структура, — у [docs/dropezone-analysis.md](docs/dropezone-analysis.md).

## Локальна перевірка без Telegram
Без `BOT_TOKEN` сервер працює в DEV-режимі: гра відкривається просто в браузері.
Щоб перевірити обмін між двома гравцями, відкрий дві вкладки:
`http://localhost:3100/?as=2001&name=ivan` і `http://localhost:3100/?as=2002&name=petro`.
Тестова база лежить у `data/` — видали теку, щоб почати з нуля.

## Де зараз працює гра
На Railway: https://avtodrop-production.up.railway.app (проєкт і сервіс `avtodrop`, база на томі `/data`).
Оновлення: з теки гри `railway up --detach`. Локальний запуск нижче — лише запасний варіант, не вмикай його одночасно з Railway.

## Запуск для гравців з цього комп'ютера
1. У `.env` мають бути `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_KEY` (зразок — `.env.example`).
2. Двічі клікни `start-live.cmd` (або `node tools/live.mjs`). Відкриється безкоштовний тунель Cloudflare з https-адресою,
   і бот сам поставить кнопку «Грати» на цю адресу. Гравці заходять через бота.
3. Гра працює, доки відкрите вікно і ввімкнений комп'ютер. Оновлення коду підхоплюються самі (сервер перезапускається,
   тунель і його адреса лишаються). Нова адреса буває лише після повторного запуску скрипта — тоді гравцям, у яких
   відкривається помилка Cloudflare 1033, треба закрити гру й відкрити чат бота заново (або надіслати /start).
Справжні гравці зберігаються в `data-live/` (тестова база в `data/` не чіпається).

## Підключення до Telegram
1. У @BotFather: `/newbot` → отримай токен. Потім `/newapp` (або Bot Settings → Configure Mini App) і вкажи адресу гри.
2. Гра має працювати по **https** (Telegram не відкриває http). На VPS це робить Caddy автоматично (див. нижче).
3. Задай змінні середовища та перезапусти сервер.

| Змінна | Опис |
|---|---|
| `BOT_TOKEN` | токен бота від @BotFather. Вмикає перевірку підпису Telegram, сповіщення та оплату зірками |
| `WEBAPP_URL` | публічна https-адреса гри, напр. `https://avtodrop.example.com` (кнопка «Грати» в боті) |
| `ADMIN_IDS` | Telegram ID адмінів через кому |
| `ADMIN_KEY` | ключ для входу в адмін-панель з браузера (довгий і випадковий) |
| `PORT` | порт (за замовчуванням 3100) |
| `DATA_DIR` | тека бази (за замовчуванням `./data`) — це вся резервна копія |
| `DEV=1` | дозволити вхід без Telegram. **Ніколи не вмикай на сервері** |

Команди адміна в боті: `/admin` (кнопка адмін-панелі), `/promo КОД СУМА КІЛЬКІСТЬ [ДНІВ]`, `/give ID СУМА`, `/stats`.

## Адмін-панель
`/admin.html` — огляд гри (гравці, гроші, машини за класами, зірки, казино), пошук гравців і повна картка кожного:
машини з тюнінгом і номерами, склад деталей, ключі, дропи, платежі, сповіщення. Звідти можна нараховувати й списувати гривні,
видавати й вилучати машини, деталі, ключі й номери (номер видається лише якщо він вільний), міняти рівень і кількість місць,
писати гравцю та блокувати його. «Пошук номерів і авто» шукає по інвентарю всіх гравців: повний номер показує, вільний він
чи хто ним володіє; частина номера («7777», «KA») — усі схожі; назва моделі — у кого є така машина.
Також: усі лоти ринку й аукціони (з можливістю зняти), промокоди, платежі та журнал усіх дій адмінів. Кнопка «Назад у гру» повертає в гру.
Як увійти:
- локально в DEV-режимі — просто відкрий `http://localhost:3100/admin.html` (або «Меню → Адмін-панель» у грі);
- на сервері — з ключем `ADMIN_KEY`, або з Telegram командою `/admin` у боті (твій ID має бути в `ADMIN_IDS`).
Небезпечні дії (списати, вилучити, заблокувати) потребують двох натискань. Заблокований гравець не може грати, його лоти знімаються з ринку.

## Оплата Telegram Stars
Пакети гривень задані в `public/shared.js` (`PACKS`). Бот сам створює рахунок (`createInvoiceLink`, валюта XTR),
підтверджує `pre_checkout_query` і зараховує гроші після `successful_payment` — кожен платіж лише один раз.
За правилами Telegram у боті є команда `/paysupport`. Ігрову валюту не можна вивести.

## Деплой на Railway
1. `railway init` (або обрати наявний проєкт), потім `railway up` з теки гри — збирається з `Dockerfile` (`railway.json` задає healthcheck і 1 репліку: бот має працювати в одному екземплярі).
2. Додати Volume, змонтований у `/data` (там база гравців), і змінну `RAILWAY_RUN_UID=0`, щоб процес міг писати в том.
3. Змінні: `BOT_TOKEN`, `ADMIN_IDS`, `ADMIN_KEY`, `WEBAPP_URL=https://<домен від Railway>`. `PORT` Railway задає сам.
4. Перед запуском на Railway зупини локальний `start-live.cmd`: два екземпляри бота одночасно заважають один одному.

## Деплой на VPS із Docker
1. DNS-запис `A` домену → IP сервера.
2. Скопіюй проєкт, `cp .env.example .env`, заповни `DOMAIN`, `BOT_TOKEN`, `WEBAPP_URL=https://DOMAIN`, `ADMIN_IDS`.
3. `docker compose up -d --build` — Caddy сам отримає HTTPS-сертифікат (порти 80 і 443 мають бути відкриті).

## Що покращено порівняно з подібними іграми
- **Гонки з навичкою**: старт на зелений (+4% / фальстарт −8%) і 4 перемикання передач по тахометру. Деталі реально впливають: КПП зменшує втрати на перемиканні, шини й підвіска — пробуксовку на старті. Ідеальна їзда перемагає навіть «складного» суперника.
- **Обмін між гравцями**: авто (разом з деталями й номером) + гривні з обох боків, повторна перевірка в момент підтвердження.
- **Ринок і аукціони**: фіксована ціна або торги з антиснайпінгом, повернення перебитих ставок.
- **Чесні кейси**: видимі шанси, гарантія через 30 відкриттів і перевірювана випадковість (HMAC-SHA256).
- **Україна/СРСР** як окрема країна з кейсом, колекцією і секретним прототипом. 6 країн із секретними машинами.
- **Баланс**: ціна кейса ≈ 55% середньої вартості дропу, продаж машини — 40% ціни моделі. Кейси окупаються доходом гаража (3%/год), а обмежує їх кількість місць.
- Захист: дохід «заморожується» при кожній зміні гаража, тож перекидання авто між акаунтами не дає подвійного доходу.

## Структура
- `public/shared.js` — машини, кейси, формули (спільні для сервера й клієнта)
- `src/game.js` — уся ігрова логіка, `src/db.js` — схема SQLite
- `src/bot.js` — Telegram-бот (long polling), `src/auth.js` — перевірка initData
- `public/app.js`, `public/car.js`, `public/style.css` — Mini App
