АВТОДРОП — промпти для картинок деталей (11 штук, один стиль)
=============================================================

ЯК КОРИСТУВАТИСЯ
1. Копіюй промпт повністю (рядок після «PROMPT:») у Gemini або інший генератор.
2. Збережи картинку в  C:\Users\vdm\Desktop\avtodrop\raw-cars\  з назвою з цього файлу:
   eng.png, turbo.png, exhaust.png, gearbox.png, suspension.png, wheels.png, brakes.png, body.png,
   motor.png, battery.png, reducer.png (деталі електромобілів)
3. Запусти  npm run cars  (або python -I tools/prepare_cars.py) — фон виріжеться, картинка ляже в public/parts/.
   Гра підхопить її протягом 30 секунд. Колір рівня (Stock…Race) гра малює сама — картинка одна на тип.
