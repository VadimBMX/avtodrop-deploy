АВТОДРОП — промпти для картинок машин
======================================

ЯК КОРИСТУВАТИСЯ
1. Копіюй промпт машини повністю (рядок після «PROMPT:») у Gemini або інший генератор.
   Якщо машина вийшла не збоку або дивиться ліворуч — просто згенеруй ще раз.
2. Збережи картинку в теку  C:\Users\vdm\Desktop\avtodrop\raw-cars\
   і назви її НОМЕРОМ машини з цього файлу: 001.png, 002.jpg, 057.webp ...
3. Запусти в теці гри команду:  npm run cars
   Вона сама вирізає фон, обрізає, перевертає за потреби й кладе картинку в гру.
   Гра підхопить нові картинки протягом 30 секунд, перезапускати нічого не треба.
   НОВА машина (без фото її ще немає в грі — номери 151+) з'явиться після перезапуску сервера
   або деплою: npm run cars сам допише її в public/car-photos.js. Потім: npm run paint-masks -- <ID>.

Якщо вже маєш картинку з прозорим фоном — можна покласти її одразу в
C:\Users\vdm\Desktop\avtodrop\public\cars\  з назвою ID машини (напр. vaz-2107.png) і запустити  npm run car-photos
